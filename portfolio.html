👨‍💻 ประวัติส่วนตัว

สวัสดีครับ ผมชื่อ นายธนโชติ วรรณวิสิทธิ์

นี่คือพื้นที่รวบรวมผลงาน กิจกรรม และสิ่งที่ผมภูมิใจ

💻 1. โครงงาน / งานวิทยาการคำนวณ

รายละเอียดชิ้นงาน:

การสร้างเว็บไซต์แฟ้มสะสมผลงานด้วย HTML และ CSS เพื่อรวบรวมข้อมูลส่วนตัว ผลงาน และกิจกรรมต่าง ๆ

สิ่งที่ได้เรียนรู้: ได้เรียนรู้การใช้แท็ก HTML การจัดหน้าเว็บไซต์ด้วย CSS และการนำเว็บไซต์ขึ้น GitHub Pages

🎨 2. ผลงานการสร้างงาน 3D

รายละเอียดชิ้นงาน:

การออกแบบและสร้างโมเดล 3D โดยใช้โปรแกรม Autodesk 3ds Max

สิ่งที่ได้เรียนรู้: ได้ฝึกการออกแบบวัตถุ การสร้างรูปทรง การใส่วัสดุ และการจัดแสง

🍫 3. ผลงานโมเดลช็อกโกแลต

รายละเอียดชิ้นงาน:

การสร้างโมเดลช็อกโกแลตแบบแท่ง และออกแบบบรรจุภัณฑ์ด้วยโปรแกรม 3D

🏫 4. กิจกรรมและประสบการณ์

เข้าร่วมกิจกรรมการเรียนรู้ด้านเทคโนโลยี วิทยาการคำนวณ และกิจกรรมต่าง ๆ ของโรงเรียน

🏆 5. เกียรติบัตร

สามารถเพิ่มเกียรติบัตรที่ได้รับ จากกิจกรรมหรือการอบรมต่าง ๆ ลงในส่วนนี้ได้
