🏆 ผลงานและกิจกรรม

🔬 วิทยากรวันวิทยาศาสตร์

เข้าร่วมกิจกรรมในบทบาทวิทยากร ทำหน้าที่ให้ความรู้และสื่อสารข้อมูล ทางวิทยาศาสตร์แก่ผู้เข้าร่วมกิจกรรม

สิ่งที่ได้รับ: ได้พัฒนาทักษะการพูด การนำเสนอ ความมั่นใจ และการทำงานร่วมกับผู้อื่น

🚫 กิจกรรมต่อต้านยาเสพติด

เข้าร่วมกิจกรรมรณรงค์ต่อต้านยาเสพติด และร่วมสร้างความตระหนักถึงผลกระทบ ของยาเสพติดในสังคม

สิ่งที่ได้รับ: ความรับผิดชอบ การทำงานร่วมกัน และการมีส่วนร่วมกับกิจกรรมของโรงเรียน

💻 ค่ายเทคโนโลยี

เข้าร่วมค่ายยกระดับผลสัมฤทธิ์ ทางการเรียนเทคโนโลยี ผ่านกิจกรรมเสริมความรู้ และทักษะที่สอดคล้องกับหลักสูตร

สิ่งที่ได้รับ: ความรู้ด้านเทคโนโลยีและทักษะ การแก้ไขปัญหาอย่างเป็นระบบ

🌐 เว็บไซต์ Portfolio

สร้างเว็บไซต์ Portfolio ด้วย HTML และ CSS เพื่อรวบรวมข้อมูลส่วนตัว ประวัติการศึกษา ผลงาน ทักษะ และข้อมูลการติดต่อ

สิ่งที่ได้รับ: ฝึกการเขียนโค้ด การออกแบบเว็บไซต์ และการจัดโครงสร้างหน้าเว็บ
